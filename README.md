# Маркетолог базы и воронок — скилл для Claude Code

Скилл для продюсеров онлайн-школ и инфопродуктов, у которых уже есть база клиентов и несколько продуктов, а
системной работы с этой базой нет. Помогает ответить на вопросы:

- где на пути клиента теряются люди и деньги (карта пути, восемь этапов);
- что предложить человеку после первой покупки, после курса, после эфира;
- как устроена лестница продуктов и какая ступень какую кормит;
- кому, что, когда и через какой канал писать; как строить цепочки и дожимы, не выжигая базу;
- как понять, что сработало: контрольная группа, метки, рубли на человека.

Это не генератор текстов. Скилл проектирует: сегмент, момент, предложение, замер. Письма пишет копирайтер (человек
или другой скилл), а «Отправить» нажимает человек.

## Установка

**Через терминал** (нужен установленный git):

    git clone https://github.com/KomarovIvan83/marketer-skill ~/.claude/skills/marketer

**Без терминала:** на странице репозитория нажмите зелёную кнопку «Code» → «Download ZIP», распакуйте и
положите папку в `~/.claude/skills/` под именем `marketer` (на Windows — `%USERPROFILE%\.claude\skills\marketer`).
В итоге файл `SKILL.md` должен лежать по пути `~/.claude/skills/marketer/SKILL.md`.

Для Codex и других агентов: это обычные файлы, достаточно попросить агента прочитать `SKILL.md` и выполнять
написанное.

## Первый запуск

Скилл универсален, цифры вашего бизнеса в нём не зашиты. Откройте Claude Code и напишите, например:

> Работаем как маркетолог базы. Заполни `references/your-layer.md` интервью со мной.

Скилл спросит про ваши продукты, цены, откуда приходят клиенты, где хранится база, чем вы рассылаете, что уже
пробовали. Дальше он будет опираться на ваши ответы, а не на американскую методику для подписочных сервисов.
Список цифр, которые стоит достать из базы, — `references/what-to-measure.md`.

Примеры запросов:

- «Построй карту пути клиента и найди, где мы теряем больше всего денег».
- «Что предложить выпускникам основного курса через три месяца после финала?»
- «Спроектируй цепочку для тех, кто был на эфире и не купил».
- «Посчитай, окупится ли мост из мини-курса в основной, и как это замерить».

## Чего ждать и чего нет

- Наблюдения о том, что работает, взяты из практики одной онлайн-школы хобби. Это гипотезы: проверяйте на своих
  данных. В `your-layer.md` есть правила и места под ваши.
- Скилл ничего не отправляет и не публикует сам.
- Библиотека Хейнса на английском и написана для SaaS: не всё к вам относится, `references/library.md` показывает,
  что берём, а что пропускаем.
