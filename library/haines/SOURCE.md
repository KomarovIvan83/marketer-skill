# Откуда эта папка

- **Источник:** [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — набор маркетинговых
  скиллов Кори Хейнса (агентство Conversion Factory, рассылка Swipe Files).
- **Версия:** коммит `dda3841f0b294e01e93b1541486beefbfab0915e` от 02.10.2026.
- **Лицензия:** MIT, файл `LICENSE` рядом (Copyright (c) 2025 Corey Haines). Копировать и переделывать можно,
  лицензию оставлять при копии.
- **Что взято:** 16 из 50 скиллов — про работу с базой, путь клиента, запуски и повторные продажи. Не взяты SEO,
  реклама, сайты, App Store, копирайтинг.
- **Что изменено:** главный файл каждого скилла у Хейнса называется `SKILL.md`, здесь он переименован в `main.md`,
  чтобы Claude Code и Codex не приняли копию за отдельные рабочие скиллы. Папки `evals` (проверочные примеры) не
  копировались. Тексты не правились.

Это справка, а не инструкция к исполнению. Порядок работы задаёт `SKILL.md` в корне репозитория, правила —
`references/your-layer.md`. Упоминания у Хейнса о файле `product-marketing.md`, о сервисах (Customer.io, Stripe,
Klaviyo) и о законах США к российским школам не относятся. Что в каком файле и что применимо — в
`references/library.md`.

Обновлять целиком: новая копия с новым коммитом, затем пересмотреть `references/library.md`. Руками не править.
